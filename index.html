02 / THE DEVELOPER

KZINDEPENDENT
DEVELOPER

I care about what happens under the surface - how systems communicate, how code scales, and how small technical decisions shape the player experience.

My work is centered around Roblox development with Luau. I build features from the ground up, structure code into reusable modules, and refine existing systems with maintainability and performance in mind.

Whether it’s a combat mechanic, an NPC behavior system, a custom interface, or a Studio plugin, my goal stays the same: make it work reliably, keep it understandable, and leave it easy to extend.
